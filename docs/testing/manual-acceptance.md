# COMTool Avalonia 人工验收清单

本文档列出必须由真人在目标平台完成的验收项。功能测试矩阵中 `Manual` 列引用的每个 ID 都必须出现在下表中，签收文件必须包含矩阵用到的全部 `WIN-*` 项。

- 适用对象：Windows 候选包为主；`WIN-15` 为 Linux 桌面补充项。
- 执行时机：候选包构建完成、自动化门禁通过后，正式包提升前。
- 证据：截图、日志或录屏统一放在 `docs/testing/evidence/`，并在签收文件中填写相对路径。
- 结果只有 `PASS` / `FAIL`；`FAIL` 或空证据不得提升为正式包。

## 记录方式

1. 按 `docs/testing/signoffs/README.md` 的命名规则创建签收文件。
2. 逐项填写 `PASS` 和证据路径；任一 `WIN-*` 项失败则整体不通过。
3. `WIN-09` 同时写入 `soak` 字段，`hours` 不得小于 8。
4. 签收文件与本清单一起提交，作为正式包提升依据。
