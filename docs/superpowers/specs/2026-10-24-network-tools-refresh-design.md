# 网络扫描器 / 网络服务器刷新设计

## 目标

让网络扫描只探测固定七个服务端口，扫描可中断；统一扫描器和网络服务器窗口的数值对齐；工具窗口不再作为主窗口附属窗口，可被主窗口盖住。

## 范围

- 网络扫描器：只扫描 SSH / RDP / VNC / FTP / Telnet / Rlogin / HTTP（22 / 3389 / 5900 / 21 / 23 / 513 / 80）；删除“其他端口”探测集合和结果列；结果表从 10 列减为 9 列。
- 网络扫描器：扫描中提供“停止”按钮；停止后保留已发现结果，状态显示“已停止（已发现 N 台）”；关闭窗口仍取消扫描。
- 网络扫描器：修复 `NetworkScanner` 的取消传播，Ping、TCP 连接和反向 DNS 在外部取消时重新抛出取消异常；停止后迟到的进度不得覆盖“已停止”状态。
- 网络扫描器：IP 范围五个输入框统一宽度、数字水平/垂直居中；结果表表头和数据行共用固定列宽，IP/名称左对齐，七个状态列等宽、勾叉居中。
- 网络服务器：HTTP/TFTP 的端口与秒数 `NumericUpDown` 统一宽度、数值居中；标签保持右对齐。
- 工具窗口：打开方式由 `Show(this)` 改为 `Show()`，`WindowStartupLocation` 改为 `CenterScreen`；仍单实例，再次点工具菜单激活已有窗口；主窗口关闭时显式关闭所有工具窗口。
- 共享打开逻辑会让网络服务器、网络扫描仪、端口扫描仪都成为独立窗口；端口扫描仪的扫描逻辑不变。
- 端口扫描仪的“已知端口”列表不变。

## 非目标

- 不调整扫描超时、并发数或 DNS 策略。
- 不修改网络服务器的协议实现、服务器列表或配置格式。
- 不改版本号；不推送远端。

## 验收

- 网络扫描只探测七个服务端口；结果表无“其他端口”列。
- 扫描中可停止，已发现行保留，状态为“已停止（已发现 N 台）”；关闭窗口仍能取消。
- 扫描器 IP 输入、结果表、网络服务器端口/秒数控件对齐。
- 工具窗口 `Owner == null`，可被主窗口盖住；重复点工具菜单不产生第二实例；关闭主窗口会关闭工具窗口。
- 全量测试 gate、Linux E2E、Windows win-x64 单文件 R2R 就地发布通过；无 `.bak-*`，`BAK_COUNT=0`。

## 约束

- 测试名保持 `ClassName.MethodName`。
- 版本保持 `0.01`。
- Windows 产物为 win-x64 单文件 R2R，就地覆盖，不生成 `.bak-*`。
- 未经确认不执行 `git push`。
