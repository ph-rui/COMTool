# Bundled icon fonts

These fonts are vendored from the `qtawesome` 1.4.2 wheel so the Avalonia shell
uses the same icon glyphs as the Python UI.

| File | Family | Version | License |
| --- | --- | --- | --- |
| `fontawesome6-solid.ttf` | Font Awesome 6 Free Solid | 6.7.2 | SIL OFL 1.1 |
| `materialdesignicons6.ttf` | Material Design Icons | 6.9.96 | Apache License 2.0 |
| `phosphor.ttf` | Phosphor | 1.3.0 | MIT |

Sources:

- Font Awesome: https://fontawesome.com/
- Material Design Icons: https://pictogrammers.com/library/mdi/
- Phosphor Icons: https://phosphoricons.com/
